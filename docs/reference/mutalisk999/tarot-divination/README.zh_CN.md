# 塔罗占卜（Tarot Divination）

把 AI Passport 变成一副随身塔罗牌：78 张完整牌库，单张问当下，三牌阵看过去、现在与未来，2.4 英寸屏上呈现公有领域的 Rider-Waite-Smith（1909）经典牌面。

## 发布信息

- **标题**：塔罗占卜
- **简介**：把整套韦特塔罗装进口袋。按键洗牌，单张抽牌看今日，或摊开过去/现在/未来三牌阵。每张牌都是 1909 年经典牌面，正位逆位一屏呈现，配中文关键词与短解读。
- **应用名（kebab-case）**：`tarot-divination`

## 功能

- **开机直达应用**：固件直接进入封面页，无主菜单；不复用基线硬件测试 demo 的界面。
- **完整 78 张牌库**：22 张大阿卡纳 + 56 张小阿卡纳，每张牌配正/逆位关键词与一段中文短解读，牌义遵循通行韦特体系。
- **嵌入牌面**：78 张经典扫描图（1909，公有领域）以两档分辨率编译进固件——解读页与单张揭示用 120 × 180,三牌阵小卡位用 64 × 96（约占 8MB Flash 的 4.2MB;运行时不做任何图片缩放）。
- **单张抽牌**：按键播放洗牌动画，第一次按下即由硬件随机数一次定下整副牌阵,翻出真实牌面后自动进入解读页。
- **三牌阵**：过去 / 现在 / 未来,逐次按键翻开,之后可逐张浏览。
- **正逆位**：每张牌约 50% 概率逆位。逆位牌面真实上下颠倒(按行翻转复制进静态 RAM 缓冲——本板做图形变换需要离屏层,不可用),配朱砂描边与「逆位」徽记。
- **电量显示**：右上角实时百分比,数秒刷新一次;低于 20% 转朱砂色。

## 交互

三个按键驱动全部功能。

- **封面页**：上/下选择牌阵（单张 / 三牌阵）,确定键开始。
- **洗牌页**：确定键洗牌并翻开下一张;全部翻开后按确定键进入解读页;长按确定键回封面。
- **解读页**：上/下滚动解读文本;三牌阵下按确定键在 过去 → 现在 → 未来 间切换;长按确定键回封面。

## 可复用的工程要点

- **每种显示尺寸一套图**：LVGL 在无 PSRAM 板上无法缩放图片(变换需要离屏层),生成器为每种卡位尺寸各生成一套 1:1 图。
- **不用变换的逆位**：倒置显示是把图按行倒序复制进静态 RAM 缓冲(full 43KB + mini 12KB),而非 `lv_image` 旋转。
- **字库清单即契约**：从源码提取 UI 字符清单,据此再生 Noto Sans SC 子集;文案与清单脱节时门禁中的主机测试会失败。
- **纯逻辑保持可测**：牌库数据、抽牌引擎(可注入种子的 xorshift32 + 部分 Fisher-Yates)、导航与符号几何均不依赖 IDF/LVGL,由仓库门禁中的主机测试覆盖。
